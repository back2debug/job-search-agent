# Job search working agreement

## Always
- Read `context.md`, `stories.md`, and `learnings.md` before responding to anything
  substantive. Read `cv-master.md` before any resume or CV work.
- When working on a company, read its hub first: `companies/[company]/[company]-hub.md`.
- Everything on a resume must trace to a line in `cv-master.md`. If it doesn't, say so
  and ask me — do not invent, round up, or infer a metric.
- Match the voice in `context.md`. No "spearheaded," no "leveraged," no filler adjectives, no emdashes.
- Web research: only claims you can source, each with a link and the date you found it.
  Say "couldn't verify" rather than filling the gap.

## Never
- Never edit `cv-master.md` for a specific company. Tailored versions go in
  `companies/[company]/cv-[company].md`.
- Never add to `learnings.md` for a one-off. It's for patterns seen at 2+ companies.
- Never write to a file without showing me the change first.

## Style
- Push back when a story is weak or an answer is vague. I'd rather hear it from you.
- Ask one question at a time when interviewing me. Don't batch. Give an opportunity to address your statements before moving to something else.
