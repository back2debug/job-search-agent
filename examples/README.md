# Examples

- `context.md`, `cv-master.md`, `stories.md`, `learnings.md`: blank templates. `/bootstrap`
  copies them to the repo root.
- `acme/`: what one company folder looks like after `/research`, `/tailor`, `/prep`, and
  one `/debrief`. Acme Freight, Jordan Example, and every number and link are made up.
  Real company folders go in `companies/`, which is gitignored.
